# Semantic video contract (draft)

Draft for [milestone 10](../milestones/10-semantic-core.md). Nothing here is built. [Project files](project-files.md) stays the authoritative contract until milestone 10 merges this draft into it, then this file is deleted. The decisions behind it are [0019](../decisions/0019-semantic-video-elements-and-style.md), [0020](../decisions/0020-channel-brand-and-shared-styles.md), [0021](../decisions/0021-sound-transitions-and-bookends.md) and [0023](../decisions/0023-motion-system-and-lottie-templates.md).

The examples show intended shape, not settled syntax. Milestone 10 settles the grammar and makes the examples tested fixtures, like the project files examples.

## The model

```
recording ──analysis──▶ elements/<take>.jsonl   facts, committed
                              │
brand/brand.kdl ─┐            ▼
formats/<f>.kdl ─┼─cascade─▶ style rules ──build──▶ cut.lock ──render──▶ cuts
<video>/format.kdl ┘                       ▲        instances, committed, generated
                       cut.kdl ────────────┘
                       chapters, takes, manual cuts, overrides, derived cuts
```

Content is what the video says: chapters, takes, a person's cuts. Style is how it looks and sounds, including pacing. The build is pure: `shot-core` resolves the cascade and applies rules to elements with no IO, so the same files give the same lock.

## Files

```
<channel repo>/
  brand/
    brand.kdl           channel style: fonts, colors, logo, sounds, bookends, rules
    fonts/ sounds/      in git
    media/              bumper videos (ignored)
  formats/<format>.kdl  format style: rules and switches per format
  videos/<slug>/
    format.kdl          video style: names its format, holds only what differs
    cut.kdl             content and overrides
    cut.lock            generated by every build, committed, never edited
    elements/<take>.jsonl   committed facts of each take
    sounds/             the video's own sounds
```

`format.kdl` stops being a copy of the preset ([0016](../decisions/0016-product-effects-as-format-settings.md)). It names its format and holds only differences, so a change to the channel's format reaches every unshipped video. Edit scopes map to files: only here is an override in `cut.kdl`, this video is `format.kdl`, this format is `formats/<format>.kdl`, the channel is `brand/brand.kdl`.

## Elements

`elements/<take>.jsonl`, JSON Lines sorted by `t`, one element per line. Every element has `kind`, `t` and, if it spans time, `to`, in take media time. `by` names the source and version. Findings carry `confidence` (0 to 100).

| Source | Kinds |
| --- | --- |
| Transcript | `word` (`text`), `sentence`, `silence`, `pause`, `filler`, `retake`, `misspoken`, `emphasis` |
| Mentions | `url` (`url`, `host`), `code` (`text`), `product` (`name`) |
| Screen | `click`, `typing`, `idle`, `ocr` (`text`, box) |
| Camera | `face` (box), `expression` (`label`, strength) |
| Script | `chapter`, `beat` (`index`), `tag` (`name`, from `{name}` in `script.md`) |
| Markers | `marker` (`label`): M, Z, B and labeled markers from the record hotkeys |
| Claude | `claim`, `punchline`, `aside`, `topic-shift`, `needs-source`, from the transcript only |

```json
{"kind":"silence","t":4200000,"to":5100000,"confidence":96,"by":"vad@silero-5"}
{"kind":"url","t":22000000,"to":23400000,"url":"https://github.com/coderscantina/shot-studio/pull/1","host":"github","by":"transcript"}
{"kind":"click","t":6200000,"x":2210,"y":640,"by":"events"}
{"kind":"punchline","t":40100000,"to":42800000,"by":"claude"}
```

An element is identified by kind, take and `t`. Re-analysis is an explicit command (`shot analyze --video <dir> --take t01`) whose diff is reviewed. Builds never run analysis.

## Style rules

A rule selects elements and applies effects. Selectors and effects are closed sets; an unknown one is an error with file, line and column.

```kdl
on silence min=500_000 confidence=80 {
    cut breath=250_000
}
on chapter-start {
    transition dip length=500_000
    overlay chapter-band for=2_500_000
    sfx swoosh
}
on url host=github {
    overlay link-card for=6_000_000
    sfx pop
}
on click {
    zoom 160 hold=1_500_000
}
on punchline {
    overlay pop for=1_200_000 { text "🔥" }
}
```

- **Selectors**: an element kind with attribute filters, plus `chapter-start`, `chapter-end`, `video-start` and `video-end`.
- **Effects**: `cut` (pacing: confident findings removed, unsure ones queued), `layout`, `zoom`, `overlay <template>` with parameters (the [overlay templates](project-files.md#overlay-templates), plus `chapter-band`, `end-card`, `callout` and `pop`), `sfx`, `transition`, `music`, `captions`.
- **Cascade**: brand, then format, then video. A later layer replaces a rule with the same selector, or turns it off with `on <selector> off`.

## Brand

```kdl
import "https://github.com/coderscantina/shot-styles" rev="3f2a91c" style=cantina
fonts heading="brand/fonts/Display-Bold.otf" body=geist mono=geist-mono
colors accent="#C8F25A" text="#F4F6F8" card="#141821" background="#101418"
logo "brand/logo.svg"
sounds zoom=whoosh card=pop click=click transition=swoosh pop=pop
intro bumper="brand/media/intro.mp4" title=#true
outro bumper="brand/media/outro.mp4"
end-card length=12_000_000
camera shape=rounded corners=24 border=0 shadow=soft
```

Motion, sounds per phase and Lottie templates also live in the brand:

```kdl
motion reaction=reactive opinion=editorial product-tour=launch tutorial=calm
preset launch tempo=40 bounce=10 density=30 stagger=60 beat-sync=#false
preset reactive tempo=80 bounce=60 density=70 stagger=40 beat-sync=#true
sounds card-travel=whoosh card-settle=tick pop-settle=pop transition=stinger
transition stinger="brand/stinger.json" peak=400_000
template quote-card file="brand/quote-card.json" {
    slot quote text required=#true
    slot author text
    slot accent color
}
```

- `motion` maps each format to a preset; a format style may pick another. Feel controls are integers from 0 to 100.
- `transition stinger=` names the Lottie and the time its frame is fully covered, where the cut happens underneath. Other transitions are `cut`, `dissolve`, `dip`, `mask-wipe` and `zoom-through`.
- A `template` declares a Lottie template: its file and typed slots (`text`, `color`, `integer`, `time`). The declaration is its spec; the file's content hash enters the lock and every chunk the template draws on. A built-in template is re-skinned by declaring a template of the same name whose slots cover its parameters.
- A Lottie that uses anything velato cannot render is refused when added, with every unsupported feature and layer listed.

A video overrides fields with a `brand` node in its `format.kdl`, for example `brand { colors accent="#FF7A59" }`. Bundled fonts are named bare, repo fonts by path. A missing bumper is an export error.

## `cut.kdl` after migration

`review`, `ignore`, rule-made `remove`, `zoom ... by=` and rule-made `overlay` nodes leave `cut.kdl`; their results are in the lock. What stays: captions and caption fixes, chapters, takes with `keep` and `remove by=manual`, placed `sfx` and `music` cues, overrides, derived cuts.

```kdl
chapter "Hook" {
    take t01 {
        keep from=0 to=12_000_000
        music "sources/bed.mp3" at=0 gain=-18 duck=-12
        sfx ding at=9_200_000 gain=-6
        override filler at=9_800_000 { keep }
        override click at=6_200_000 { zoom off }
        override url at=22_000_000 { overlay link-card { accent #true } }
    }
}
```

An override names an element by kind and `at`, and replaces or turns off what the rules gave it. K in the review queue writes `{ keep }`, C writes `{ cut }`.

## `cut.lock`

Every build writes it in a stable order: per take, each instance with its range, values, the element and the rule layer that made it. It is the input of the renderer and of the chunk hash.

```kdl
style "3f2a91c"
take t01 {
    cut from=4_200_000 to=5_100_000 element=silence at=4_200_000 rule=brand
    zoom 160 from=6_200_000 to=8_400_000 x=2210 y=640 element=click at=6_200_000 rule=format
    overlay link-card from=22_000_000 to=28_000_000 element=url at=22_000_000 rule=override {
        url "https://github.com/coderscantina/shot-studio/pull/1"
        accent #true
    }
    sfx pop at=22_000_000 element=url at=22_000_000 rule=brand
}
```

Shipping freezes the lock at the release tag. `shot restyle <slug>` rebuilds a shipped video as a new release.

## Chunk hash changes

The hash reads instances from the lock instead of `cut.kdl`, so caching behaves as today. Additions: brand fields where something branded draws, font files by content, the camera style where the camera shows, and at a chapter edge both sides of the transition. Rule layer and element provenance are not part of it, like zoom provenance today.
