# A cli in rust

## Intro

- Welcome, today we build a command line tool in Rust
- By the end you have a binary that parses arguments and prints colored output

## Arguments

- Create the project with cargo new
- Add the clap crate to parse the arguments
- Clap gives us help text and validation for free

## Colors

- Add colors with the owo colors crate
- Run the tool: green for success, red for errors
